# 401comp.com

Source for the 401comp.com website — a single static HTML/CSS page introducing independent computer help and 401comp software projects. Deployed via GitHub Pages; `CNAME` points it at the custom domain.

This repository is the website only. The private 401comp field-service app is not included here or published from this repository.

To preview locally, just open `index.html` in a browser — no build step.
